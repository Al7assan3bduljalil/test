# 🏠 نظام إدارة المنزل

تطبيق ويب بسيط باللغة العربية لتنظيم شؤون المنزل والأسرة. يعمل بالكامل داخل المتصفح دون خادم أو تثبيت، وتُحفظ البيانات محليًا (localStorage).

## المزايا

- **لوحة التحكم**: ملخص المهام والفواتير والمصاريف وتنبيهات المخزون.
- **المهام المنزلية**: إسناد المهام لأفراد الأسرة، أولويات، مواعيد، ومهام متكررة (يومي/أسبوعي/شهري) تتجدد تلقائيًا عند إنجازها.
- **قائمة التسوق**: أصناف مصنفة مع سعر تقديري، وعند إزالة المشتراة يمكن تسجيلها مصروفًا.
- **المصاريف والميزانية**: تسجيل المصاريف حسب الفئة والشهر، مع شريط تقدم للميزانية الشهرية.
- **الفواتير**: متابعة مواعيد الاستحقاق والمتأخرات؛ الدفع يسجل مصروفًا تلقائيًا وينشئ فاتورة الشهر التالي للفواتير الشهرية.
- **المخزون**: كميات وحد أدنى للتنبيه وتواريخ انتهاء، مع زر لإضافة الغرض لقائمة التسوق.
- **الأجهزة الذكية**: إضافة أجهزة (إضاءة، مكيف، تلفاز، ستائر، أقفال، مقابس، حساسات...) مقسمة حسب الغرف، مع تشغيل/إيقاف وتحكم بالسطوع والحرارة، ومشاهد سريعة (مغادرة المنزل، العودة، وضع النوم). يدعم الأجهزة الحقيقية عبر **Home Assistant** (مثل Sonoff على eWeLink) مع تحديث فوري للحالة، إلى جانب أجهزة تجريبية للمحاكاة. دليل الإعداد: [HOME-ASSISTANT.md](HOME-ASSISTANT.md).
- **المراقبة والطقس**: طقس مباشر وتوقعات 5 أيام (خدمة Open-Meteo المجانية)، استهلاك الكهرباء والتكلفة التقديرية، حالة الأقفال، حساسات الغرف، تنبيهات ذكية، وسجل النشاط.
- **كاميرا الأطفال**: بث من كاميرا Home Assistant أو كاميرا الجهاز أو كاميرا شبكة (MJPEG/صورة متجددة)، رؤية ليلية، ملء الشاشة، عرض حرارة ورطوبة الغرفة، وكشف حركة مع تنبيه صوتي وسجل.
- **أفراد الأسرة**: إدارة الأفراد وعدد المهام المعلقة لكل فرد.
- **الإعدادات**: العملة (دينار ليبي أو دولار أمريكي)، الميزانية، تصدير/استيراد نسخة احتياطية JSON، وبيانات تجريبية.
- دعم الوضع الليلي والشاشات الصغيرة.

## التشغيل

افتح الملف `index.html` في أي متصفح حديث. أو شغّل خادمًا محليًا:

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

> لاستخدام كاميرا الجهاز يجب فتح التطبيق عبر `localhost` أو `https`. ولكاميرا شبكة بعنوان `http://` شغّل التطبيق محليًا على شبكة المنزل.

لتجربة سريعة: الإعدادات ← **تحميل بيانات تجريبية**.

## الملفات

| الملف | الوصف |
|---|---|
| `index.html` | هيكل الصفحة |
| `style.css` | التنسيقات (RTL، وضع ليلي، تصميم متجاوب) |
| `app.js` | منطق التطبيق والتخزين |
| `smart.js` | الأجهزة الذكية والطقس وكاميرا الأطفال |
| `ha.js` | الربط مع Home Assistant (WebSocket API) |
| `HOME-ASSISTANT.md` | دليل ربط Sonoff/eWeLink والكاميرا |
